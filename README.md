# Online Retail Sales Analysis

## Project Overview

This project analyzes an Online Retail dataset to identify sales trends, customer behavior, product performance, and country-wise sales patterns.

The analysis was performed using Python and Pandas, with Matplotlib used for data visualization.

## Objectives

- Analyze overall sales performance
- Identify monthly revenue trends
- Analyze country-wise revenue and order volume
- Identify top-performing products
- Analyze customer and order patterns
- Generate meaningful business insights

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

## Key Business Insights

- Total revenue: **£10.64 million**
- Total quantity sold: **5.57 million units**
- Total orders: **19,960**
- United Kingdom was the strongest market by revenue and order volume.
- **DOTCOM POSTAGE** was the highest-revenue product.
- **November 2011** was the best-performing month.
- **February 2011** recorded the lowest monthly revenue.
- Monthly revenue showed considerable fluctuations.
